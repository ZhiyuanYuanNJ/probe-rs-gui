# probe-rs-gui

基于 Dear ImGui 框架开发的 probe-rs 图形界面程序（Windows 平台）。

A Windows GUI front-end for [probe-rs](https://github.com/probe-rs/probe-rs), built with the Dear ImGui framework.

## 使用 / Usage

将本目录解压到任意位置，双击 `probe-rs-gui.exe` 启动即可。程序会在同目录下调用 `probe-rs.exe`，请确保相关文件保持在同一文件夹内。
